KEYBOARD SHORTCUTS
═══════════════════════════════════════════════════════════════════

⌘1            - Show Project Navigator (left sidebar)
⌥⌘1           - Show File Inspector (right sidebar)
⌘0            - Toggle left sidebar
⌥⌘0           - Toggle right sidebar
⌘⇧K           - Clean Build Folder
⌘B            - Build

═══════════════════════════════════════════════════════════════════
WHAT IF I DON'T SEE "TARGET MEMBERSHIP"?
═══════════════════════════════════════════════════════════════════

1. Make sure you clicked a Swift file (not a folder)
2. Make sure File Inspector (📁 icon) is selected at top
3. Scroll down in the right sidebar
4. It should be below "Text Settings" section

CHECKLIST FOR ONE FILE
═══════════════════════════════════════════════════════════════════

For "ThemeFix.swift":

□ 1. Found file in Project Navigator (left)
□ 2. Clicked on filename (turns blue)
□ 3. Right sidebar is visible
□ 4. File Inspector (📁) is selected
□ 5. Scrolled down to "Target Membership"
□ 6. Found "RaceTrian" checkbox
□ 7. Clicked to UNCHECK it (☑ → ☐)
