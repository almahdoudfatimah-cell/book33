WHAT IS "EXCLUDING FROM BUILD"?
────────────────────────────────────────────────────────────────

When you UNCHECK a file from "Target Membership":
  • The file STAYS in your Xcode project (you can still see it)
  • But it's NOT compiled (Swift ignores it during build)
  • It's like commenting out the entire file

This is better than deleting because:
  ✅ You can keep the files for reference
  ✅ No risk of losing work
  ✅ Easy to undo (just check the box again)
